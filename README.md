# 脉络 / Branchline

面向个人工作的原生 macOS 项目进度工具。

项目拥有独立主干，分支可以关联多个项目，文字记录沿时间展开，阶段成果分别合并到项目主干。

[下载最新版本](https://github.com/Ashlesha-x/branchline/releases/latest) · [更新记录](CHANGELOG.md) · [本地 AI 接口](docs/本地接口.md)

## 功能

- **项目与分支**：每个项目一条主干；分支可同时关联多个项目，阶段成果以摘要快照合并回主干。
- **三类记录**：进度、任务、会议。任务支持 DDL、依赖关系和每日 / 每周 / 每月重复。
- **多种视图**：时间轴、纵向脉络图、列表与待办，配合统一搜索和组合筛选。
- **回顾与周报**：按周、月或自选日期整理记录，生成可编辑的精简周报或完整回顾，可导出 Markdown。
- **提醒**：任务和会议的系统通知，支持相对提醒与重复会议。
- **Apple 日历**：从选定日历导入会议；新会议可勾选「同步到电脑日历」写入默认日历，已关联的会议在脉络里修改后自动写回，两边都改过时逐项处理冲突。
- **菜单栏常驻**：随时快速记录进度和任务，不占 Dock 和 ⌘Tab。
- **本地优先**：数据只存在本机，可导出完整备份或备份到 iCloud 云盘；删除可从回收站恢复。
- **AI 客户端接入**：通过本机 MCP / CLI 接口，让 Claude Desktop、Claude Code、Codex 按权限读写脉络。

## 系统要求

- Apple Silicon Mac
- macOS 15 及以上

## 安装

1. 在 [Releases](https://github.com/Ashlesha-x/branchline/releases) 下载 `Branchline-<版本>-macOS-arm64.dmg`（0.15.2 及更早版本为 .zip）。
2. 打开磁盘映像，把 `脉络.app` 拖到“应用程序”文件夹。放在“应用程序”中才能使用自动更新。
3. 应用使用临时签名，未经 Apple 公证。首次打开如被系统拦截，在访达中右键应用选择“打开”，或在终端执行：

   ```sh
   xattr -dr com.apple.quarantine /Applications/脉络.app
   ```

## 快速上手

- 首次打开是空的「个人空间」工作区。可以在侧栏左下角新建、切换、重命名工作区，每个工作区的内容互不相通；删除只能在“设置 → 通用 → 工作区”里输入名称确认。提醒来自所有工作区。
- 点击“体验示例空间”可以查看独立的演示内容，第一次进入时会有一步步的新手引导（可在设置里重新播放）。示例里的修改只在本次体验保留，不写入你的工作区。
- 应用以菜单栏模式运行。启动时打开主窗口；关闭主窗口后继续运行，菜单栏图标提供快速录入和重新打开窗口。通过菜单栏面板的“退出”结束进程。
- 在“设置（⌘,）→ 通用”打开“登录时自动启动”，使用 macOS 原生登录项。
- 在“设置 → 关于与更新”可以手动检查更新。勾选“自动更新”后，脉络每天检查一次 GitHub Releases，在后台下载新版本，点“立即重启并更新”或退出脉络时完成替换。自动更新从 0.16.0 起可用，需要应用放在可写的位置（例如“应用程序”文件夹）。

## 使用说明

- 新建项目后，在项目详情中“拉出新分支”，或从顶部“新增”创建独立分支。
- 分支可关联多个项目。共享分支的数据只有一份，项目筛选不会复制记录。
- 记录分为进度、任务和会议。可以补记过去的进度；任务结束日期可以留空，DDL 独立设置。
- 任务可以等待其他任务，循环依赖会被拒绝。完成任务前需要处理其未完成的依赖。
- 在分支详情中“合并阶段成果”，选择目标项目、引用记录和摘要。摘要是当时的文字快照，来源记录后续编辑不会改写它。可以继续分支或结束整条共享分支。
- 时间轴按实际日期显示，横向滚动查看历史和未来，也可用日期选择器定位。脉络图使用纵向彩色路线，最新在上，压缩没有事件的日期；相邻且同日的同一线路记录聚成数量节点，悬停放大、点击展开，再点击摘要查看详情。重复会议在路线图中按系列显示，在时间轴中展开具体日期。列表可按类型筛选；顶部统一搜索可查项目、分支、记录与成果摘要。
- 项目与分支的结束 / 归档日期不得早于最近一次合并日期（允许同一天）；归档也不得早于结束。旧备份缺少这些字段时可继续读取，编辑完成或归档状态时补入日期。
- 新建项目与分支随机分配颜色，优先选择差异较大的未占用色；编辑器提供可直接点选的 64 色色板，显示当前及已占用颜色；暂停和完成仍占用颜色，归档后释放。重新启用时若原色已占用，会重新分配。深色模式自动提高颜色亮度。
- 时间轴起点显示圆点，主干与分支线加粗；横向滚动条固定在下沿，纵向固定在右侧，有内容可滚动时持续显示。
- 项目状态支持进行中、暂停、完成、归档。非活跃项目默认折叠，点击箭头查看。可在详情中删除项目、分支、记录及合并成果，删除前须二次确认并自动备份，删除后可从回收站按次恢复。
- 菜单栏可快速添加文字进度和任务，会议会打开完整编辑面板以确认起止时间。

## 提醒

提醒默认不添加。在记录编辑器中添加提醒时间，首次保存时请求系统通知权限；也可到“设置 → 提醒”启用。示例空间不发送通知。支持单次会议及每天、每周、每月重复的会议；重复会议支持“仅本次 / 本次及以后 / 整个系列”编辑和删除。从时间轴或待办选择具体日期后，在详情中选择操作范围；未选择具体日期时使用系列开始日期。

系统提醒采用最多 64 条的应用级滚动队列，按时间先后安排；重复会议预排一年内的候选项。在启动、回到前台、Mac 唤醒和数据更新时刷新，应用在菜单栏常驻时自动续排。已经过去的提醒不补发，到期任务仍可在列表和菜单栏查看。相对提醒随改期重新计算；原有固定提醒在改期保存时询问是否移动。是否显示横幅和何时显示还取决于系统授权、专注模式和睡眠状态。

## 数据与备份

个人数据目录：`~/Library/Application Support/Branchline/`。本版本以 Core Data 的 SQLite 持久化保存版本化文字工作区，每次修改校验后完整提交；失败时不更新内存中的当前工作区。没有账号、云同步、文件扫描或网络调用。

“设置 → 备份与恢复 → 本机 → 导出…”生成包含工作区与草稿的迁移 JSON。恢复备份前会完整验证格式、引用、日期和依赖，然后要求确认，并在数据目录的 `Backups/` 自动另存当前工作区。不会删除旧备份或源文件。普通文字编辑不逐字保存历史；DDL、开始时间、状态、分支关联和合并操作保留关键变更记录。

“设置 → 备份与恢复 → iCloud 云盘”可以开启每日自动备份，或点“立即备份”，把所有工作区（只含有改动的）的完整 JSON 快照写入 `iCloud 云盘/脉络备份/`，无需 Apple 开发者会员。文件名带空间、时间、设备名和 UUID；自动备份只保留本机最近 30 份，更早的每月留 1 份，手动备份不会被删除。当天没有改动时自动备份会跳过。设置页列出最近的备份和上传状态（已上传 / 上传中 / 等待上传），可以直接点“恢复…”。该功能使用本机已有的 iCloud Drive 文件夹，由 macOS 负责上传，不使用 CloudKit，也不自动合并其他设备的修改。示例空间不备份。

当前工作区格式为 4，可读取格式 1—3；迁移备份格式为 2。升级写入前会保留旧工作区快照。旧版应用不能编辑新版工作区，需要回退时请使用升级前的备份。

## AI 客户端接入

脉络本身不调用任何模型。它在本机提供一个仅监听 127.0.0.1 的接口，以及应用包内的 `branchline-cli`（支持 STDIO MCP），供 Claude Desktop、Claude Code、Codex 等本机客户端按权限读写。权限在“设置与数据 → AI 客户端连接”中设置，可选关闭、只读、读取与修改。

配置方法和可用操作见 [本地接口说明](docs/本地接口.md)。

## 从源码构建

需要 Apple Silicon Mac 与 Swift 6 工具链（Xcode 或 Command Line Tools 均可），无第三方依赖。

```sh
zsh scripts/build.sh   # 构建并签名，输出 dist/脉络.app
zsh scripts/test.sh    # 运行核心检查
zsh scripts/make-dmg.sh # 打包 dist/Branchline-<版本>-macOS-arm64.dmg（先运行 build.sh）
```

持久化使用 Core Data，界面使用 SwiftUI，不依赖 SwiftData，也不需要完整的 XCTest。构建产物使用本机临时签名。

## 代码结构

- `Sources/ProgressCore`：数据模型、关系和日期校验、重复日程、持久化、示例数据。
- `Sources/Branchline`：窗口、图形布局、编辑器、详情、菜单栏、通知服务及未来集成接口。
- `Tests/ProgressCoreTests`：备份恢复、保存重开、共享关系、循环依赖、日期边界和夏令时等校验。使用自包含检查程序，不依赖完整 Xcode 的 XCTest / Testing 模块。

第一版采用完整工作区事务，适合个人文字记录。若未来积累到需要大量查询或多人协作，应先测量数据规模和交互性能，再将持久化拆分为实体查询；目前没有引入服务器或同步层。
